# City Air Quality Intelligence Dashboard

## Project Overview
City Air Quality Intelligence is a Data Analytics project that analyses air quality measurements from five monitoring stations in Chennai, Tamil Nadu.

The project uses SQL Server for data analysis and Power BI to create an interactive dashboard. It helps compare air quality across monitoring stations and understand pollution patterns.

## Objectives
- Analyse air quality measurements.
- Compare average AQI across five monitoring stations.
- Identify stations with higher AQI readings.
- Analyse PM2.5 and PM10 levels.
- Identify missing values and duplicate records.
- Present insights through an interactive Power BI dashboard.

## Tools and Technologies
- Microsoft Excel – Dataset preparation
- SQL Server – Data analysis
- SQL Server Management Studio (SSMS) – Query execution
- Power BI Desktop – Dashboard development

## Dataset Information
- Total records: 1,210
- Monitoring stations: 5
- Location: Chennai, Tamil Nadu
- Measurements: SO2, NO2, CO, PM2.5, PM10 and AQI

## Key Analysis and Findings
- Overall average AQI: 59.42
- Highest recorded AQI: 197
- Records with AQI above 150: 15
- Manali recorded the highest average AQI among the five stations.
- Missing values and duplicate Date-Station combinations were investigated.

## SQL Analysis
SQL queries were used for:
- Total record counting
- Average and maximum AQI calculations
- Station-wise comparisons
- AQI category distribution
- Missing value identification
- Duplicate record checking

## Limitations
- The analysis is based on the available dataset.
- The dashboard does not provide real-time air quality monitoring.
- The project does not predict future AQI values.

## Conclusion
This project demonstrates the use of SQL Server and Power BI to analyse real-world air quality data, identify patterns, perform data quality checks and present meaningful insights through visualisation.
